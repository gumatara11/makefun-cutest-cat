Entry for make.fun's "Draw the cutest cat" bounty: a program that writes one very cute cream-orange kitten image to `/output/entry.png`. The program copies the bundled `cat.png` (1024x1024 PNG) byte-for-byte, so every run produces identical output.

## Run it

```sh
python3 main.py
```

This writes `/output/entry.png` (creating `/output` if needed). Python 3.13, standard library only, no network.

## Files

- `main.py` — entrypoint: copies `cat.png` to `/output/entry.png`.
- `cat.png` — the kitten image (1024x1024 PNG, 972941 bytes).
